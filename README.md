# Retail Warehouse Explorer

Interactive warehouse learning website covering shared inbound/inventory, B2C fulfillment, B2B store replenishment and returns.

## Run locally

No build step or package installation is required. From this folder run:

```sh
python -m http.server 8000
```

Open `http://localhost:8000/` for the explorer, `warehouse-overview.html` for the animated layout/process guide, or `image-provenance.html` for the image gallery.
